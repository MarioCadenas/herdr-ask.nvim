*herdr-ask.txt*        Send a visual selection to a Herdr agent pane

==============================================================================
CONTENTS                                                     *herdr-ask*

  1. Requirements ............ |herdr-ask-requirements|
  2. Setup ................... |herdr-ask-setup|
  3. Actions ................. |herdr-ask-actions|
  4. Annotations ............. |herdr-ask-annotations|
  5. Commands ................ |herdr-ask-commands|
  6. Configuration ........... |herdr-ask-config|

==============================================================================
1. REQUIREMENTS                                     *herdr-ask-requirements*

  - Neovim >= 0.10 (uses |vim.system()|)
  - Herdr (https://herdr.dev) with `herdr` on $PATH
  - Neovim running inside a Herdr pane (HERDR_ENV / HERDR_WORKSPACE_ID set)

  Verify with: >
    :checkhealth herdr-ask
<
==============================================================================
2. SETUP                                                  *herdr-ask-setup*

  require("herdr-ask").setup({})            ships the default keymaps.
  Pass options to override; see |herdr-ask-config|.

==============================================================================
3. ACTIONS                                              *herdr-ask-actions*

  Both operate on the visual selection (captured as whole lines).

  Ask   Prompt for a question, then submit question + @ref + the selected
        code as one turn to a chosen agent pane.
        require("herdr-ask").ask({ global = false })

  Ref   Stage just the `@file#L...` reference into a chosen agent's input
        (no submit), so you type your own prompt around it.
        require("herdr-ask").send_ref({ global = false })

  global=false limits candidates to the current workspace; true = any pane.
  A lone candidate is used automatically; otherwise a picker is shown.

  Default keymaps (visual mode):
    <leader>ai  Ask, current workspace     <leader>aI  Ask, any pane
    <leader>ar  Ref, current workspace     <leader>aR  Ref, any pane

==============================================================================
4. ANNOTATIONS                                      *herdr-ask-annotations*

  Collect `@ref + note` pairs across one or many files, then flush the whole
  batch to one agent as a single message grouped by file.

  Annotate  Capture the selection's ref, then type a (multi-line) note in a
            scratch float; `:w` saves, `:q` cancels.
            require("herdr-ask").annotate()          (visual mode)

  Menu      Picker to send the batch (this workspace / any pane), clear it, or
            act on one annotation (jump / edit note / remove).
            require("herdr-ask").annotations_menu()  (normal mode)

  Annotated lines get a gutter sign and a dimmed end-of-line note (highlights
  HerdrAskSign / HerdrAskVirtText). The pending batch persists per project
  (git root, else cwd) under stdpath("state")/herdr-ask/, surviving a restart.
  While a buffer is open, ranges track edits via extmarks and saved positions
  update on write. On send a preview float opens (editable instruction on top,
  batch below); <CR> sends, <Esc>/q cancels.

  Default keymaps:
    <leader>aa  Annotate selection (visual)
    <leader>al  Annotations menu (normal)

==============================================================================
5. COMMANDS                                            *herdr-ask-commands*

  :[range]HerdrAsk[!]      Ask about the selection. ! = any pane.
  :[range]HerdrRef[!]      Send the reference.       ! = any pane.
  :[range]HerdrAnnotate    Annotate the selection into the batch.
  :HerdrAnnotations        Open the annotations menu.

==============================================================================
6. CONFIGURATION                                        *herdr-ask-config*

  Defaults: >
    require("herdr-ask").setup({
      herdr_bin = "herdr",
      focus_after_send = true,
      agent_kinds = nil,          -- e.g. { "claude", "codex" }
      prompt = "Ask agent ▸ ",
      format_ref = function(relpath, range) ... end,
      format_message = function(question, ref, filetype, code) ... end,
      annotations = {
        clear_after_send = true,  -- clear the batch after a successful send
        include_code = false,     -- fence referenced code under each bullet
        signs = true,             -- gutter sign + end-of-line note
        default_instruction = "Review these annotations.",
      },
      keymaps = {
        ask = "<leader>ai", ask_global = "<leader>aI",
        ref = "<leader>ar", ref_global = "<leader>aR",
        annotate = "<leader>aa", menu = "<leader>al",
      },
    })
<
  Set a keymap entry to false to skip it, or `keymaps = false` for none.
